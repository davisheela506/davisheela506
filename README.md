### 🤖 LLM-Based Agentic Architectures & OpenClaw

**LLMs | Agentic AI | Tool Use | Memory | Planning | Evaluation**

Master's thesis research on the **emergent capabilities of LLM-based agentic architectures**, with a focus on memory, planning, tool use, orchestration, and evaluation.

Worked with **OpenClaw**, a local agentic orchestration framework, and evaluated LLM performance on structured business-card information extraction.

Evaluation included:

* Field-level accuracy
* Correct / incorrect / missing / invented information
* Hallucination rate
* Honest-null rate
* False-positive rate
* Invalid-output rate
* BERTScore
* Runtime and inference efficiency

Models evaluated included **Qwen, Gemma, Ministral, and OCR-based approaches** on a Jetson AGX Orin platform.

🔗 [View Project](https://github.com/davisheela506/M2_internship_work)
